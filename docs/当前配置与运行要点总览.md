# Nougat 微调与推理：当前配置与运行要点总览

本文档汇总当前环境下的**全部配置要点、核心代码位置与关键片段、训练/推理速度与时长预估**，便于在外部 LLM 对话中敲定后续方向。未单独说明时，路径均以 AutoDL 环境为例。

---

## 一、环境与路径

| 用途 | 路径或说明 |
|------|------------|
| 项目根目录 | `/root/autodl-tmp` |
| 代码与配置 | `/root/autodl-tmp/nougat/` |
| 训练输出（checkpoint、TensorBoard） | `result_path`：`/root/autodl-tmp/nougat_exp/` → 实际为 `{result_path}/{exp_name}/{exp_version}/`，如 `nougat_exp/nougat_finetune/20260314_161742/` |
| 基座模型（0.1.0-base，与 HF 不兼容） | `/root/autodl-tmp/models/nougat-base`，需含：`config.json`、`pytorch_model.bin`、`tokenizer.json`、`aligned_model_weights.pth` 等；下载：`python -m nougat.utils.checkpoint base /root/autodl-tmp/models/nougat-base` |
| 数据根目录（BASE_DIR） | `/root/autodl-tmp/ocr_data` |
| 镜像与页级数据 | `ocr_data/out/`：每本书一目录，其下 `.mmd` / `.png`（按页码命名） |

**注意**：`/root/autodl-tmp` 所在盘（如 50G）易满，checkpoint 体积大时可把 `result_path` 改到系统盘（如 `/root/nougat_exp`）或先清理旧 run。

### 3.2 训练入口与关键逻辑（`train.py`）

- **exp_version**：未传 `--exp_version` 时用当前时间 `%Y%m%d_%H%M%S`，否则用参数。
- **Checkpoint**：按 `val/loss`（因 `val_with_generation: false`）保存最优 `save_top_k=5` 个 + `last.ckpt`；目录为 `result_path/exp_name/exp_version/`。
- **早停**：`early_stopping_patience: 5`，监控 `val/loss`，连续 5 个 epoch 不提升则停。
- **验证频率**：`val_check_interval: 800` → 每 800 个 training step 跑一次完整验证（当前约 26 次/epoch）。

关键代码片段（checkpoint + 早停）：

```python
# train.py 中
val_with_gen = config.get("val_with_generation", True)
save_top_k = config.get("save_top_k", 5)
checkpoint_callback = ModelCheckpoint(
    save_last=True,
    dirpath=Path(config.result_path) / config.exp_name / config.exp_version,
    save_top_k=save_top_k,
    monitor="val/loss" if not val_with_gen else "val/edit_dist",
    mode="min",
    filename="{epoch:02d}-{val_loss:.4f}" if not val_with_gen else "{epoch:02d}-{val_edit_dist:.4f}",
)
early_stop_patience = config.get("early_stopping_patience", 0)
if early_stop_patience > 0:
    callbacks_list.append(
        EarlyStopping(
            monitor="val/loss" if not val_with_gen else "val/edit_dist",
            mode="min",
            patience=early_stop_patience,
            verbose=True,
        )
    )
```

### 3.3 验证阶段逻辑（`lightning_module.py`）

当 `val_with_generation: false` 时，验证**只做 Teacher Forcing 前向**，只记录 `val/loss`，不调用 `model.inference()`：

```python
# lightning_module.py validation_step
if not self.config.get("val_with_generation", True):
    loss = self.model(image_tensors, decoder_input_ids, attention_masks)[0]
    if loss is not None:
        scores = {"val/loss": loss.item()}
        self.validation_step_outputs.append(scores)
        return scores
    return
# 否则走 inference + BLEU/edit_dist 等（极慢，不推荐）
```

## 四、推理配置与命令

### 4.1 生成参数（`nougat/model.py`）

推理使用「软惩罚 + 长度硬兜底」，**不使用** `no_repeat_ngram_size`（避免破坏 LaTeX 表格/公式中的合法重复）：

```python
# nougat/model.py inference() 内
max_new_tokens = getattr(self.config, "max_new_tokens", 1500)
decoder_output = self.decoder.model.generate(
    encoder_outputs=encoder_outputs,
    min_length=1,
    max_length=self.config.max_length,
    max_new_tokens=max_new_tokens,
    pad_token_id=...,
    eos_token_id=...,
    use_cache=True,
    bad_words_ids=[[self.decoder.tokenizer.unk_token_id]],
    return_dict_in_generate=True,
    output_scores=True,
    output_attentions=return_attentions,
    do_sample=False,
    repetition_penalty=getattr(self.config, "repetition_penalty", 1.15),
    stopping_criteria=StoppingCriteriaList(...),
)
```

可通过模型 config 覆盖：`repetition_penalty`、`max_new_tokens`。

### 4.2 推理脚本 `test.py`

- **加载**：`NougatModel.from_pretrained(args.checkpoint)`；`args.checkpoint` 经 `get_checkpoint()` 处理（可为目录或父目录）。
- **数据**：`--dataset` 指向 jsonl（如 `ocr_data/test.jsonl`），`--split` 默认 `test`，`--root_name` 默认 `""`。
- **结果**：`--save_path` 指定输出 JSON（含 predictions、ground_truths、各 metric 的 accuracy 等）；**仅在全部 batch 跑完后**才写文件。

示例命令（基座 / 微调）：

```bash
cd /root/autodl-tmp/nougat
export BASE_DIR=/root/autodl-tmp/ocr_data

# 基座模型推理（0.1.0-base 目录）
python test.py \
  --checkpoint /root/autodl-tmp/models/nougat-base \
  --dataset "$BASE_DIR/test.jsonl" \
  --split test \
  --save_path "$BASE_DIR/test_results_base.json" \
  --batch_size 4 \
  --root_name ""

# 微调后的 checkpoint（替换为实际 exp_version 与 ckpt 文件名）
python test.py \
  --checkpoint /root/autodl-tmp/nougat_exp/nougat_finetune/YYYYMMDD_HHMMSS/epoch=XX-val_loss=0.xxxx.ckpt \
  --dataset "$BASE_DIR/test.jsonl" \
  --split test \
  --save_path "$BASE_DIR/test_results_finetuned.json" \
  --batch_size 4 \
  --root_name ""
```

注意：若 `test.py` 或 `from_pretrained` 期望的是「目录」而非 `.ckpt` 文件，需先从 ckpt 导出权重到目录再传；当前代码中 `get_checkpoint` 会处理文件时用其 `parent` 作为目录。

## 五、现行配置下的速度与时长

### 5.1 训练（基于实测终端数据）

| 项目 | 数值 |
|------|------|
| 每 epoch 训练 batch 数 | 21 164 |
| 验证集 batch 数 | 2 836 |
| 训练速度（观测） | ~5.7 it/s（约 1.67–5.73 it/s 区间） |
| 单次完整验证速度 | ~10.3 it/s（验证 DataLoader） |
| 每 epoch 验证次数 | 21 164 / 800 ≈ **26 次** |
| 单次验证耗时 | 2 836 / 10.31 ≈ **4.6 min** |
| 每 epoch 训练耗时 | 21 164 / 5.73 ≈ **61.6 min** |
| 每 epoch 验证总耗时 | 26 × 4.6 ≈ **119 min** |
| **每 epoch 合计** | **约 181 min ≈ 3.0 h** |

### 5.2 总训练时长预估

| 情况 | 预估 |
|------|------|
| 跑满 30 epoch | 30 × 3.0 ≈ **约 90 h（约 3.75 天）** |
| 早停（patience=5） | 若 12–18 epoch 停，约 **36–54 h（约 1.5–2.25 天）** |

若将 `val_check_interval` 改为 **1.0**（每 epoch 只验证 1 次），则每 epoch ≈ 61.6 + 4.6 ≈ **66 min**，30 epoch ≈ **约 33 h**，早停约 15 epoch 时约 **16.5 h**。

### 5.3 推理速度

- 单条为自回归生成，耗时与序列长度、是否复读相关；已用 `repetition_penalty=1.15` + `max_new_tokens=1500` 限制复读与长度。
- 批量推理时 `--batch_size 4` 常用于平衡显存与吞吐；具体 it/s 依赖 GPU 与序列长度，未在本文档做固定数值标注。

## 七、磁盘与稳定性注意

- **No space left on device**：多因 `result_path` 所在盘（如 `/root/autodl-tmp` 50G）写满。解决：清理旧 run/ckpt，或将 `result_path` 改为有空间的目录（如 `/root/nougat_exp`）。
- **验证频率**：当前每 800 step 一次完整验证，每 epoch 约 26 次，占 epoch 时间约 2/3；若需提速可改为每 epoch 验证 1 次（如 `val_check_interval: 1.0`）。
